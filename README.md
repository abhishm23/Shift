# Shift (Project Sift) — Commercial Financial Audit & Reconciliation Engine

Desktop financial audit and commercial transaction reconciliation application engineered with Tauri, Rust, Python, OpenCV, and DuckDB.

## Overview
Shift is designed for high-throughput ingestion and reconciliation of enterprise financial transaction ledgers, supporting multi-million row datasets, visual table diffing, and automated anomaly detection.

## Architecture & Tech Stack
- **Desktop Shell**: Tauri v2, Rust native bindings, HTML5/Tailwind UI
- **Backend Analytics**: Python 3.11, DuckDB, Polars, OpenCV document image processing
- **Verification Engine**: Alternating QA-Developer autonomous test harness with visual Playwright verification

## Running the Application
```bash
setup.bat
run.bat
```
